## 🧰 Skills Demonstrated

- **Test design:** test plans, test cases, boundary values, negative testing
- **Testing types:** smoke, functional, exploratory, usability, keyboard accessibility, responsive and cross-device
- **Security-minded testing:** client-side validation bypass, XSS / SQL-injection input checks
- **Bug reporting:** clear reproduction steps, expected vs. actual results, severity and priority, visual evidence
- **Full QA cycle:** requirements analysis, test plan, traceability matrix, and a test summary report with a go/no-go recommendation
- **Two-build comparison:** every defect is re-checked on a clean build to separate pre-existing defects from injected ones
- **Traceability:** every bug is linked to a test case, and every failed test case to its bug
- **Tools:** Browser DevTools (Elements, Console, Network, Sources, Application/Storage, Device Toolbar), screen recording, Markdown
